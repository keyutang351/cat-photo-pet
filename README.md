# 把自家猫带进 ChatGPT 🐾

上传一张猫照，让她在你工作时陪在桌边。鼠标绕着她走，她会转头看；靠近她，她会侧躺、翻出肚皮，再坐起来。毛色、额纹、眼睛和尾巴取自你自己的照片。

## 给猫友的用法

1. 在支持本地技能的 Codex 环境中安装本技能。可以下载仓库 ZIP 并解压，把包含 `SKILL.md` 的目录命名为 `cat-photo-pet`，放进 `~/.codex/skills/`。重新打开会话。
2. 开启图像生成和 **Pets** 插件。生成和激活取决于你的客户端是否支持 ChatGPT Work 宠物。使用本地桌面包需要客户端提供 **hatch-pet**。工具脚本使用 Python 3 和 Pillow。
3. 上传一张正脸照即可。如果尾巴或侧面的花纹很特别，可以再加一张侧身照。复制下面这句话。

> 用 $cat-photo-pet 把照片里的猫做成我的 ChatGPT 宠物。她叫栗子，保留她的花纹，鼠标碰到她时让她打滚。做好后选中她。

## 让光标变成逗猫棒（可选，Mac）

打开宠物浮窗，在解压后的技能目录运行：

```sh
bash start-wand.command
```

第一次编译需要 Apple Command Line Tools（可用 `xcode-select --install` 安装）。看到菜单栏 🪶 后，选择「3 秒后定位猫咪」，随即将鼠标放在猫身中央。定位完成后，鼠标进入约 90 点的范围会出现一根羽毛棒，离开后恢复。点击和拖动穿过羽毛棒继续作用于原窗口。窗口重开或展开导致猫的位置改变时，重新定位一次。通过 🪶 菜单退出，也可以关闭启动它的终端。每台想使用逗猫棒的 Mac 需要各自启动一次。系统若不允许隐藏原指针，羽毛棒会伴随原指针显示。

整个角色都会响应悬停。在生成环境里提交自己的猫照即可，照片无需上传到本仓库。
